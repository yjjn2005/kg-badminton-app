# KG 배드민턴 스마트 매칭 시스템

KG배드민턴 클럽 코트 배정 및 대기열 관리 웹앱.
KG클럽 2026 임원회의방의 핵심 운영 고충(2인 대기 무한 밀림·게스트 5인 제한·연겜 융통성)을 디지털로 해소하기 위해 제작.

## 🚀 라이브 데모

GitHub Pages: `https://yjjn2005.github.io/kg-badminton-app/`

## ✨ 핵심 기능

| 기능 | 설명 |
|---|---|
| **4인 자동 매칭** | 대기열 4명 모이면 자동으로 빈 코트에 배정 |
| **15분 카운트다운** | 코트별 남은 시간 실시간 표시 (60초↓ 위급 알림) |
| **★ Override 강제결합** | 2인 대기 그룹을 직전 경기자와 결합 — 연겜 1회 허용 |
| **QR 도착 인증** | 회원별 고유 QR로 도착 인증 → 자동 대기열 등록 |
| **카톡 호출** | 차례 도래 시 카톡으로 호출 메시지 전송 |
| **게스트 5인 자동 차단** | 일일 게스트 한도 초과 시 시스템 차단 |
| **회원 관리** | 119명 초기 데이터 + 회원 추가/삭제 |
| **실시간 통계** | 회원별 게임 수 랭킹 |
| **관리자 모드** | 드래그앤드롭 수동 배정 |

## 🎨 디자인

- 럭셔리 다크 테마 (딥 네이비 + 샴페인 골드)
- Pretendard 한국어 폰트
- 50대↑ 67% 사용자 친화 — 큰 글씨·큰 버튼

## 📱 사용 환경

- 메인 운영: 체육관 거치형 태블릿 (12.7인치 권장)
- 회원: 개인 스마트폰
- 전광판: 50~60인치 TV (HDMI 미러링)

## 🛠️ 기술 스택

- 단일 HTML 파일 (Vanilla JS)
- LocalStorage 영속화
- [qrcodejs](https://github.com/davidshimjs/qrcodejs) — QR 생성
- [html5-qrcode](https://github.com/mebjas/html5-qrcode) — QR 스캐너
- Pretendard 웹폰트

## 📦 로컬 실행

```bash
cd kg_badminton_app
python -m http.server 8774
# 브라우저에서 http://localhost:8774 접속
```
