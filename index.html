📖 앱 운용방법 안내
1
체육관 도착 시 — 내 QR 보여주기
화면 아래 🆔 내 QR 버튼을 누르고, 본인 이름을 선택해 QR 코드를 띄우세요. 체육관 메인 태블릿에서 📷 QR 도착 인증을 통해 인식되면 자동으로 대기열에 등록됩니다.
2
차례 기다리기 — 대기 순번 확인
오른쪽 대기열 패널에서 본인 이름과 순번을 확인할 수 있습니다.
4명이 모이면 자동으로 빈 코트에 배정됩니다.
3
차례가 되면 — 카톡 호출 알림 받기
총무님이 💬 호출 버튼을 누르면 클럽 단톡방에 「유재진, 임대혁님, 코트 1로 입장해 주세요」 메시지가 전달됩니다.
4
경기 후 — 자동으로 대기 해제
경기 종료 버튼을 누르면 자동으로 대기열에서 빠집니다. 새 게임에 참여하려면 다시 + 회원 등록 또는 QR 인증을 진행하세요.
1
운영 시작 — 데이터 자동 초기화 확인
날짜가 바뀌면 데이터는 자동 초기화됩니다. 필요 시 하단 🔄 오늘 데이터 초기화로 수동 초기화 가능.
2
회원 등록 — 두 가지 방법
방법 ① 사이드바 + 회원 등록 → 이름 검색 → 다중 선택 → 등록
방법 ② 📷 QR 도착 인증 → 회원 QR 스캔 → 자동 1인 대기 등록
3
★ 2인 대기 무한 밀림 해소 — Override 강제결합
본 시스템의 가장 핵심 기능
① 하단 🔒 관리자 모드 클릭 → 활성화
② 2인 대기 그룹에 나타나는 ↻ 직전 경기자와 결합 클릭
③ 시스템이 직전 경기 종료자 중 2명을 자동 결합 → 코트 자동 배정
④ 결합된 회원은 ★ 마크가 표시되어 연겜 1회 허용 상태로 식별됨
4
게스트 등록 — 5인 자동 차단
사이드바 탭 + 게스트 등록 → 인원수 선택. 일일 5명 한도 초과 시 시스템이 자동으로 차단합니다.
5
카톡 호출 — 클립보드 + 단톡방
코트 카드의 💬 호출 클릭 → 호출 메시지가 클립보드에 자동 복사 → 클럽 단톡방에 붙여넣기 한 번이면 호출 완료.
6
회원 추가/삭제 — 신입 회원 등록
하단 👥 회원 관리 → 신규 등록 탭에서 이름·성별·출생연도·급수 입력. 삭제는 회원 목록에서 ✕ 버튼.
7
드래그앤드롭 수동 배정 (고급)
관리자 모드 ON 상태에서 4명이 모인 대기 그룹을 마우스로 끌어다 원하는 빈 코트에 놓으면 즉시 배정됩니다.
!
기본 운영 규칙
▸ 4인 1조 복식 매칭이 표준
▸ 경기 시간 기본 15분 (+5분 연장 가능)
▸ 게스트 일일 최대 5명 (대진클럽 우선)
▸ 연속 게임은 임원진 판단으로 Override 시 1회 허용
▸ 데이터는 매일 자동 초기화 (게임 기록은 통계로 보존)
Q
QR 카메라가 안 보입니다
QR 스캐너는 보안상 HTTPS 환경에서만 동작합니다. GitHub Pages 배포 URL(https://...)로 접속하세요. http:// 로컬은 일부 브라우저에서 차단됩니다.
Q
카톡으로 자동 발송 가능한가요?
현재 v1.0은 클립보드 복사 + 단톡방 붙여넣기 방식입니다. 완전 자동화는 카카오 비즈니스 채널 승인(유료, 사업자등록 필요)이 별도로 요구됩니다.
Q
데이터 백업은 어떻게?
현재 데이터는 이 기기 브라우저(LocalStorage)에만 저장됩니다. 브라우저 캐시 삭제 시 데이터 소실 우려가 있으므로, 운영용 메인 태블릿은 캐시 자동 삭제를 끄거나 시크릿 모드를 피하세요.
Q
동명이인은 어떻게 구분되나요?
이름 외에 출생연도와 회원번호(No.)가 함께 표시되어 구분됩니다. 예: 김희연1(1968년생·1A급), 김희연2(1970년생·A급).
Q
실수로 다른 회원을 배정했습니다
관리자 모드 ON → 해당 코트의 경기 종료 클릭 → 다시 올바른 4명으로 등록. 통계상 1회로 기록되긴 하지만 분쟁 방지에 효과적.
